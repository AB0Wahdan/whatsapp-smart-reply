# 💬 WhatsApp Smart Reply

> AI reply drafting and task capture for WhatsApp

![n8n](https://img.shields.io/badge/n8n-1f6feb?style=flat-square) ![Evolution API](https://img.shields.io/badge/Evolution%20API-1f6feb?style=flat-square) ![LLM](https://img.shields.io/badge/LLM-1f6feb?style=flat-square) ![Google Tasks](https://img.shields.io/badge/Google%20Tasks-1f6feb?style=flat-square)

## 📌 Overview
An n8n workflow that watches a WhatsApp conversation through Evolution API, drafts context-aware replies from chat history, and automatically adds action items to Google Tasks.

## ✨ Features
- Listens to incoming WhatsApp messages
- Drafts replies using conversation history
- Extracts tasks and adds them to Google Tasks

## 🛠️ Tech Stack
n8n, Evolution API, LLM, Google Tasks

## 🚀 Getting Started
```bash
# 1. Set up Evolution API and connect WhatsApp
# 2. Import workflow.json into n8n
# 3. Add your credentials inside n8n (never commit them)
# 4. Activate the workflow
```
